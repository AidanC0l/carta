# 💖 Carta de Amor - San Valentín 💖

## Para ti, mi persona especial 💕

Desde el momento en que nuestras vidas se cruzaron, supe que todo sería diferente. Este pequeño proyecto no es solo un programa, 
es una carta digital hecha para ti. Quiero que cada vez que lo abras, recuerdes cuánto significas para mí y que es mi primer proyecto así.

---

## 🌷 Sobre este detalle 🌷

Este programa ha sido creado en **Java** con mucho cariño, con una interfaz dulce y decorada especialmente para ti. Contiene:

✨ Un mensaje inicial con un título grande para recordarte lo especial que eres.

✨ Un botón en forma de **corazón** para pasar a un mensaje lleno de amor y buenos deseos para tu día.

✨ Un fondo decorado con **tulipanes** y quería agregar a la hola diablo, porque sé que te encantan, pero no di como por el momento. 💕

✨ Un botón final, también en forma de **corazón**, para cerrar la carta. 💖

---

## 💡 Cómo ejecutar este detalle

Para poder observar la carta, sigue estos pasos:

1. Asegúrate de tener instalado **Java** en tu computadora.
2. Descarga los archivos del proyecto y coloca la imagen `hellokitty.png` en la misma carpeta.
3. Compila y ejecuta el programa con el siguiente comando en la terminal:
   
   ```bash
   javac CartaDeAmor.java
   java CartaDeAmor
   ```

4. Lee la carta. 💕
